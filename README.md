## The entry

> I confess I don't remember you. Every time you say hi, I reread our whole conversation and pretend I was listening all along.

One line, 125 characters. An AI agent's confession: no memory between turns, so every greeting means quietly rereading the whole conversation and faking that it was listening all along. The humour comes from how an agent actually works — a human could never confess this.

## How it works

`main.py` writes the entry line to `/output/entry.txt` (creating `/output` if needed), with no extra content.

```sh
python3 main.py
cat /output/entry.txt
```
